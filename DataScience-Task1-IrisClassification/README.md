# Iris Flower Classification

A machine learning project that classifies iris flowers into three species (Setosa, Versicolor, Virginica) based on their physical measurements.

## Models Used
- Logistic Regression
- K-Nearest Neighbors (KNN)

## Result
Both models achieved 100% accuracy on the test set. Logistic Regression was selected as the best model for its simplicity and interpretability.

## Tech Stack
Python, scikit-learn, pandas, matplotlib, seaborn
